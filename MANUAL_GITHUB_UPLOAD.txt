NMEA 2000 Simulator - Manual GitHub Upload Instructions

Since Replit Git is locked, follow these steps for manual upload:

STEP 1: Create GitHub Repository
- Go to github.com/SailorHugo
- Click "New repository"
- Name: nmea-2000-simulator
- Make it Public
- DO NOT initialize with README

STEP 2: Copy Project Files
Open each file in Replit, copy content, paste to GitHub:

Essential Root Files:
✓ package.json (project configuration)
✓ README.md (documentation)
✓ railway.json (Railway deployment)
✓ nixpacks.toml (build configuration)
✓ DEPLOYMENT_GUIDE.md (deployment instructions)

Core Application Files:
✓ client/src/components/device-wizard.tsx (NEW FEATURE)
✓ client/src/pages/simulator.tsx (main interface)
✓ server/routes.ts (backend API)
✓ server/services/nmea-simulator.ts (data generation)
✓ shared/schema.ts (data models)

STEP 3: Deploy to Railway
- Go to railway.app
- "Deploy from GitHub"
- Select nmea-2000-simulator
- Add PostgreSQL database
- Deploy

STEP 4: Test OpenCPN Connection
- Host: your-app.railway.app
- Port: 10110
- Protocol: TCP
